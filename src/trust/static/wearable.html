Bring your own readings

On iPhone, Health → profile → Export All Health Data. Extract export.xml from the ZIP, then choose it here. Only supported Apple Watch samples are read.

Processed on this computer. The raw export is not saved; recent supported readings stay in server memory until restart. No health data is committed to Git or sent to a cloud service.

Two input paths

1 · Scripted walkthroughVisible demo values are synthetic and useful for presenting the interface.
2 · Apple Health importLoads heart rate, respiratory rate, oxygen saturation and sleeping wrist temperature when present.
3 · Optional iPhone ShortcutA token-protected local endpoint accepts Health samples over the same local network. Setup is in README.
Prototype on Earth data and optional personal Health exports. No clinical or spaceflight validation.
