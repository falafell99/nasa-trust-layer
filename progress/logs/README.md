# progress/logs/

Один файл на человека: `<имя>.md`. Агенты человека пишут в файл этого человека. Только добавление в конец (append-only), чужие журналы не править.

Формат записи (из `AGENTS.md`):

```
## YYYY-MM-DD HH:MM (Будапешт) — кто (человек/агент)
- Сделано:
- Числа (с знаменателем и источником):
- Проблемы:
- Дальше:
- Уверенность: [Точно] / [Вероятно] / [Догадка]
```

Перед записью: `git pull --rebase`. После: маленький коммит и push.
