# prompts/

Промпты для внешних моделей (GPT, Perplexity, Gemini) и контекст для них.

- `context-pack-for-llms.md` — полный контекст проекта и промпты (создан до решений ночи 14→15 ноября). **Устарел частично:**
  - считает, что тестовая часть CinC 2015 (500 записей) доступна для оценки; на самом деле она закрыта, hold-out делается из 750 обучающих;
  - принимает «157 истинных из 500» (из закрытой части), не использовать;
  - трактует 12,5% как долю неподтверждённых тревог; это доля слабых окон Pixel Watch при ходьбе;
  - не знает про VTaC как второй набор, про шлюз как перенос между доменами, про обрезку на 5:00, про две сцены демо, про правила остановки.
  Актуальное состояние: `docs/03`, `docs/05`, `docs/10`.
- `addendum-nasa-data.md` — дополнительный промпт: прочитать список данных NASA и партнёров на странице нашего челленджа.
- `addendum-verification.md` — промпт на проверку неподтверждённых утверждений.

Правила использования промптов: вставлять в модель контекст целиком (не сужать), просить метки [Точно]/[Вероятно]/[Догадка], ссылки на первоисточники и явное «не нашёл». Ответ сохранять в `docs/raw/` и вносить строку в `docs/07`.
