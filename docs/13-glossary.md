# 13. Глоссарий

| Термин | Значение в проекте |
|---|---|
| Trust Layer | слой между датчиком и экипажем: подписывает тревогу оценкой доверия и причиной, не скрывая её |
| Триггер | простое правило (как на мониторе), поднимающее тревогу |
| Шлюз качества | модуль, оценивающий, можно ли доверять окну сигнала; выход q от 0 до 1 |
| q (балл качества) | не вероятность; величина для порогов |
| p_true | оценка того, что событие настоящее (выход проверки) |
| Статус | Действуй (красный), Проверь (жёлтый), Скорее ложная / Не подтверждено (серый) |
| Виртуальный датчик | код, который из записи отдаёт пакеты как из живого датчика |
| Буфер 5 минут | скользящая память последних 5 минут сигнала для проверки события (≈450 КБ) |
| Абляция V0–V3 | V0 только ЭКГ; V1 +шлюз; V2 +согласованность каналов; V3 полный |
| Hold-out | часть из 750 записей CinC, зафиксированная до подбора признаков и порогов |
| Официальный score CinC 2015 | `100·(TP+TN)/(TP+TN+FP+5·FN)` |
| TP / FN / TN / FP | настоящая тревога оставлена / пропущена / ложная отклонена / ложная оставлена |
| Правило трёх | при 0 событий из N верхняя 95%-граница доли ≈ 3/N |
| Охват (coverage) | доля тревог, получивших определённый статус «Действуй» или «Скорее ложная» |
| CinC 2015 | PhysioNet/CinC Challenge 2015: ложные тревоги в реанимации |
| VTaC | набор VT-тревог (PhysioNet), 5 037 размеченных |
| BUT QDB | набор Брненского университета: качество носимой ЭКГ |
| NST | MIT-BIH Noise Stress Test: наборы шума |
| WFDB | формат записей PhysioNet; библиотека `wfdb` |
| CMO | Crew Medical Officer |
| CDSS | clinical decision support system |
| CMO-DA | Crew Medical Officer Digital Assistant, проект NASA (не бортовая система) |
| OSDR | NASA Open Science Data Repository |
| TRISH | Translational Research Institute for Space Health |
| SQI | signal quality index |
| ACC | акселерометр |
| PPG | фотоплетизмограмма (пульсовая волна) |
| ABP | инвазивное артериальное давление (не носимый канал) |
| Перенос между доменами | применение шлюза, обученного на BUT, к данным CinC |
| Утечка | попадание информации о будущем или метках в признаки |
